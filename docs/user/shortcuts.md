# Teclado

> **Estado:** Aplicable.

Tab y Mayús+Tab recorren controles. Intro envía formularios y Espacio activa botones enfocados. Escape cierra
los diálogos que lo permiten. No se capturan letras sueltas mientras se escribe. Los enlaces de navegación
funcionan con teclado y el foco se mantiene visible.

**Ctrl + K** (Cmd + K en macOS) abre el registro rápido desde cualquier vista, igual que el botón **Registrar comida**
de la barra superior. Escribe lo que comiste en una frase y elige el momento del día, o escribe «agua 500» o
«peso 72,4». Intro guarda y Escape cierra sin guardar.
