# Preguntas frecuentes

> **Estado:** Aplicable.

## ¿Se necesita una cuenta?

No. Los registros personales son locales.

## ¿Se sincroniza con el teléfono?

V1 intercambia copias compatibles. No incluye sincronización ni fusión de historiales.

## ¿Tiene funciones de pago?

No hay funciones personales bloqueadas ni artículos de Nibi de pago.

## ¿Diagnostica o prescribe?

No. Los cálculos y referencias sirven para registrar y entender hábitos, no para diagnosticar ni prescribir.
