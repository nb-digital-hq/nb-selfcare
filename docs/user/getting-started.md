# Primeros pasos

> **Estado:** Aplicable.

Al abrir se completa un perfil con datos necesarios para las estimaciones: nacimiento, sexo usado por las
fórmulas, altura, peso y objetivos. Es posible importar una copia compatible desde Ajustes. Los datos se conservan
localmente. Las estimaciones no sustituyen una evaluación clínica.

Hoy reúne energía, agua, hábitos, diario, lo registrado durante el día en ambos equipos y el avance de la semana.
La barra lateral lleva a cada registro; Ctrl + K abre el registro rápido. Idioma, tema y tamaño se cambian en Ajustes
sin reiniciar. Antes de usar el producto con datos reales debe completarse su validación de escritorio.
