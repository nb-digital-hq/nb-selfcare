# Ayuno

> **Estado:** Aplicable.

Antes de comenzar se comprueban condiciones de seguridad del perfil y sesiones recientes. Si aparece una
advertencia, se revisa y se considera la alternativa; no se oculta para iniciar más rápido. Las fases descritas
son aproximaciones generales. La persona puede terminar una sesión sin castigo. Ante malestar se prioriza el
cuidado, no alcanzar una duración en la aplicación.
