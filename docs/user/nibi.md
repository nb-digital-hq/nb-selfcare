# Nibi

> **Estado:** Aplicable.

Nibi acompaña la actividad registrada con monedas locales, artículos gratuitos y rachas sin penalización.
No hay compras reales ni cosméticos de pago. Registrar medicamentos no concede recompensas. La apariencia se
guarda en la base y forma parte de la copia. Las sesiones de respiración son una guía de bienestar, no tratamiento.
