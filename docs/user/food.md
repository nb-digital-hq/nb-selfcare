# Comida y agua

> **Estado:** Aplicable.

Comida permite buscar en el catálogo local, indicar gramos y momento del día, revisar nutrientes y registrar agua.
El analizador de frases propone cantidades y alimentos; se revisa antes de guardar. Es determinista y puede no
reconocer una frase. Los datos de catálogo son referencias, no mediciones de una preparación concreta.

La consulta de código de barras puede usar Open Food Facts con consentimiento. La calidad y disponibilidad del
dato externo dependen de su catálogo. Un resultado remoto no habilita envío de datos de salud.
