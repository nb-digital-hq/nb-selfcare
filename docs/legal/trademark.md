# Marcas

> **Estado:** Aplicable.

Apache 2.0 cubre el código y no concede derechos de marca. Los nombres NB, NB Digital, NB SelfCare y sus logotipos
identifican el producto oficial. Una bifurcación debe evitar confusión de procedencia y conservar los avisos de
licencia. No se atribuye aquí un registro marcario ni una jurisdicción que no se haya acreditado.
