# Política de seguridad

> **Estado:** Aplicable.

La comunicación de vulnerabilidades sigue [SECURITY.md](../../SECURITY.md). No deben adjuntarse copias de salud,
rutas privadas, diario ni credenciales a incidencias públicas. Los informes deben incluir versión, plataforma y
pasos con datos de demostración. Las dependencias y firmas se revisan antes de distribuir.
