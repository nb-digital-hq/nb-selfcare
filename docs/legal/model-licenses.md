# Modelos y recursos de análisis

> **Estado:** Aplicable.

Esta versión no incorpora modelos de inteligencia artificial ni pesos descargables. El analizador de texto es
código determinista local. Añadir modelos exigiría revisar licencia, procedencia, tamaño, privacidad y distribución
mediante una decisión específica; no se heredan licencias o modelos del reproductor.
