# Recursos de marca

> **Estado:** Aplicable. Las marcas y logotipos de NB Digital quedan fuera de la licencia del código
> ([marcas](../../legal/trademark.md)).

| Archivo | Qué es |
|---|---|
| `NB_SelfCare.svg` | El logotipo con sus colores de origen, para documentos y páginas |
| `app-icon.png` | El icono de la aplicación, 256 px |

Dentro de la aplicación el logotipo toma el color de cada tema ([marca](../../design/branding.md)).
Las capturas y el vídeo de demostración se generan con `node scripts/qa/materiales.mjs` sobre el perfil sintético
descrito en [pruebas](../../developer/testing.md).
