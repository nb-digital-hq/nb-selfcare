# Glosario

> **Estado:** Aplicable.

| Término | Significado |
|---|---|
| IPC | Puente tipado entre la interfaz y el runtime |
| Tendencia | Suavizado de pesajes; no es una medición adicional |
| TDEE | Estimación del gasto diario de energía |
| MET | Equivalente metabólico utilizado para estimar actividad |
| NOVA | Clasificación del procesamiento del alimento cuando hay dato |
| Copia | Instantánea local que permite sustituir el historial al restaurar |
| Modo Papel | Tema estable de alto contraste y sin movimiento |
| Nibi | Acompañante visual con recompensas locales gratuitas |
