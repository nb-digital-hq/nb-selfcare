# Internacionalización

> **Estado:** Aplicable.

Los diccionarios de `src/lib/i18n/` tienen español como forma de referencia e inglés y portugués con las mismas
claves. `Forma<Textos>` comprueba estructura y firmas. `idioma.svelte.ts` cambia los diccionarios sin reinicio,
persiste la preferencia y resuelve cambios concurrentes sin que una carga tardía reemplace la elección reciente.

El runtime conserva su idioma para bandeja, selectores y avisos. Los datos escritos por la persona se muestran
como se registraron. Las claves de catálogos internos deben traducirse antes de presentarse.
