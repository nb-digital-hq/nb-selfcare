# Convención de commits

> **Estado:** Aplicable.

Se usa Conventional Commits en español con firma DCO (`git commit -s`). El mensaje explica el motivo y las
validaciones. La entrega inicial se prepara como un único commit cuando el producto esté completo y revisado.
No se incluyen coautores automáticos ni datos personales en documentación. Las reglas completas están en
[AGENTS.md](../../AGENTS.md).
