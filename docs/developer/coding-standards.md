# Estándares de código

> **Estado:** Aplicable.

Los identificadores y comentarios propios están en español. Los comentarios explican el motivo. Se prefieren
cambios acotados, tipos generados y responsabilidades claras. No se inventan APIs ni se duplican reglas entre
Rust y TypeScript. Las escrituras validan datos en Rust aunque el formulario ya los compruebe.

Se ejecutan formato, lint, tipos, guardianes y pruebas. Cada defecto corregido necesita regresión. No se suprimen
comprobaciones para ocultar capacidades sin interfaz o documentación sin evidencia.
