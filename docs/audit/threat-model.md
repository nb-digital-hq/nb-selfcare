# Modelo de amenazas

> **Estado:** Aplicable.

| Riesgo | Control | Límite |
|---|---|---|
| Copia corrupta o de versión futura | Inspección, transacción y respaldo previo | No cifra el archivo |
| Fuga por registros | Campos permitidos y redacción | Exige revisión de nuevas llamadas |
| Salida de red involuntaria | Puerta única, consentimiento y CSP | Necesita QA del binario |
| Webview con acceso excesivo | Capabilities mínimas y puente centralizado | El sistema operativo debe estar protegido |
| Pérdida por migración | Respaldo y reversión completa | Se deben conservar copias fuera del mismo disco |
| Aviso clínico confundido con garantía | Texto explicativo y registro manual | No sustituye supervisión profesional |

No se garantiza protección frente a un sistema operativo comprometido o una persona con acceso a la sesión abierta.
